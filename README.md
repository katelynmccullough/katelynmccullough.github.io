## ✧ About the Project

This is my personal link-in-bio website, designed and developed as a custom alternative to Linktree.

I wanted something simple, functional, and a little more *me* — combining a minimal black-and-white aesthetic with cherry-red and soft-pink accents, rounded buttons, and subtle interactive details.

The website brings together my social media, coding projects, and professional profiles in one place.

## ♡ Features

- Responsive, mobile-friendly layout
- Custom circular profile photo
- Rounded, interactive link buttons
- Soft hover animations and transitions
- Custom typography and color palette
- Direct links to LinkedIn, GitHub, and TikTok
- Free hosting through GitHub Pages

## ✧ Built With

- **HTML5** — Website structure
- **CSS3** — Styling, responsive layout, and animations
- **Google Fonts** — Typography
- **Git & GitHub** — Version control
- **GitHub Pages** — Website hosting
- **Visual Studio Code** — Development

No frameworks, templates, or paid website builders. Just HTML, CSS, and a little creativity.
